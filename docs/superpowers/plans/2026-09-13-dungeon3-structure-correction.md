# Dungeon3 资源组合与地图逻辑修正

## 原图证据

资源规则由 `scripts/extract-dungeon3-rules.mjs` 从 Dungeon3.tmx 提取，裁剪不完整时直接报错。坐标均为 TMX 的原始格坐标，包含负坐标。

| 用途 | 原始图层 / 坐标 | 组合约束 |
| --- | --- | --- |
| 水波 | Water_details / (-17,-2)，4×2 | 使用 Water_detilazation（water_details_animation.png）的逐格动画，整组仅放在水格 |
| 墙段 | Walls2 / (6,15)，2×3 | 保留墙顶、墙面、墙脚三行，横向重复 |
| 墙内门 | Walls2 / (4,15)，2×3 | 门属于墙体；当前生成关闭的壁龛门，背后有碰撞墙；不占桥梁通路，不循环开关 |
| 地面机关 | Objects0 / (-22,7)，2×2 | 完整 plate_trap，按动画阶段启用伤害 |
| 喷火墙机关 | Objects1 / (-12,3)，2×6 | 保留龙头及全部火焰行；各格使用原始动画；只对正在显示火焰的格判伤害 |
| 平台立面 | Floor / (-11,9)，1×2 | 位于高台南缘，碰撞阻止直接跨越；楼梯处留开口 |
| 桥拱 | Floor3 / (-12,18)，6×2 | 完整拱面，仅在桥下有足够水域时放置 |
| 楼梯 | Floor / (-6,9)，5×3 | 不旋转透视资源；保留左右端帽和三行台阶，只重复中间列以适配通路 |

TMX 的图层覆盖顺序是 Water → 水下墙/水波 → Floor3 → Floor2 → Floor → Walls → Objects。图层名不是 Tiled 提供的可行走高度元数据；生成器需要另外建立高度和连接关系。当前采用从北向南 2、1、0 的台地高度，水平连接同高台地，垂直连接经楼梯下降一层。地板详情对应 Floor、Floor2、Floor3，墙体、台地边界、楼梯开口与碰撞使用同一份几何数据。

## 主题房间布局

房间不再把大型组合当作最后一步随机装饰。生成顺序固定为：房间拓扑与主题 → 主通路/安全通路 → 主题大型组合与成组机关 → 水域/铺装 → 少量散装装饰。房间外框仍遵守 3×3 槽位边界，避免为了容纳大物件直接扩大房间而让相邻房间粘连；主题使用独立的内部 `layout` 保留区决定 landmark、hazard lane 与 safe lane。

每层主题列表至少包含一间 shrine、crypt、gauntlet 和 flooded，额外房间才会复用 crypt/gallery。因此以下是每个对应主题房间的实际生成规则：

| 主题 | 实际生成组合 | 房间内位置与通路规则 |
| --- | --- | --- |
| 祭坛 shrine | 1 组完整 `Statue_fire` 5×5，共 25 个原始格；1 条 64×96 石板祭坛轴线 | 火焰雕像完整放在房间北侧一边，不再把组合伸到墙外后只露出局部；中央保留 64px 安全通路，石板使用连接蒙版选边角/中心块，不重复某一个源角块 |
| 墓室 crypt | 每间固定 4 组 3×2 棺椁，左右各两组；中央 96px 石板墓道 | 棺椁先占左右墓葬区，再给中心过道；不会再在统一房间空白区里随机找位置，避免大型棺椁组合放不下 |
| 陷阱回廊 gauntlet | 3 行连续 4×1 地刺，共 12 个地刺格；1 条 64px 绕行石板带 | 地刺三行紧邻组成 4×3 危险阵，放在回廊一侧；另一侧从入口到出口保留连续安全通路，不要求玩家吃必伤 |
| 积水房 flooded | 原有两个南侧缺口 + 一个不对称北侧 2×2 积水口；64px 中央石板脊线 | 水切入房间边缘但不切断中心通路；水面从 ripple / foam / long / small 四种完整组合中铺设，并另放 underwater ruin 层，避免每间房都是同一矩形水池 |
| 展廊 gallery | 少量散装陈设，可带 1 组棺椁 | 作为低密度变化房，不与核心主题争抢大型组合规则 |

所有主题铺装只描述连续区域，`dungeon3-renderer.js` 再根据相邻格关系选 `n/e/s/w`、四角和 `center`。这样石板区域不会再重复 `plates` 图集某一块角落而显示成零散圆点。

### 资源数量与位置口径

资源数量按“完整组合”计，而不是按屏幕上看见了几个 sprite 计：祭坛雕像一组就是 5×5/25 格；每个 crypt 固定四组棺椁；gauntlet 固定三组 4×1 地刺。由于 4–9 房间图会额外生成 crypt/gallery，棺椁总数会随种子增加，但核心四主题各至少一间。水面组合数量依可用水格和组合尺寸决定，不承诺固定总数；生成器优先尝试较大的完整水面组合，再用小组合补细节。

位置使用房间相对坐标而不是世界固定坐标：地图种子决定主题落在哪个槽位，但 landmark/hazard/safe lane 在该主题房内部的结构是确定的。这使随机性发生在“房间出现在哪里、额外房是什么”，而不是发生在“完整组合能不能塞进去”。

## 验证

- 原始 TMX 提取可重现，完整组合及资源帧索引校验。
- 多种种子验证门归属墙体、楼梯归属高度连接、机关避开重要锚点。
- 主题回归检查完整 5×5 火焰雕像、四棺椁墓室、连续 4×3 地刺阵、三处以上积水切口及连续石板路径。
- 玩家及地面 Boss 使用真实移动碰撞器沿导航路径穿过桥和台阶。
- 大体型通路按半径 26 校验；地图格导航为 16，Boss 使用自己的碰撞半径，避免寻路与移动净空不一致。
- 浏览器确认水波、地面机关和喷火墙动画显示，检查控制台错误。
