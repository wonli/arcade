# Dungeon v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix production identity/audio defects and deepen dungeon variety with real monster sprites, three room layouts, and a stronger two-phase floor-5 boss.

**Architecture:** Keep browser compatibility concerns isolated in `identity.js`, audio generation in `ambient.js`, deterministic combat/boss rules in `combat.js`, asset classification in `scene.js`/asset helpers, and Phaser orchestration in `scene.js`. Reuse the current five-floor run instead of introducing a new dungeon framework.

**Tech Stack:** JavaScript, Phaser, Svelte 5, Web Audio API, Node test runner

**Spec:** `docs/superpowers/specs/2026-09-11-dungeon-v2-design.md`

## Global Constraints

- No new external asset pack or runtime dependency.
- Keep five floors, portal progression, player controls, rarity, potions, and active skill.
- No persistence, inventory, or pathfinding framework.
- Preserve English and Simplified Chinese UI behavior.
